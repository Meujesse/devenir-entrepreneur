# Devenir entrepreneur — Anna

Activités interactives du Genially « Bonus Claude » (formation FUUUUsion, Meujesse Learning).
Anna est l'avatar qui accompagne l'apprenant·e ; sa voix est la voix ElevenLabs « Anna », ses clips vidéo sont animés avec Higgsfield (Wan 2.7).

- `activite-anna-intro.html` — Anna se présente (vidéo 16:9, 21 s).
- `activite-anna-conversation.html` — rencontre « à côté d'Anna » en vidéo : la vidéo se fige, l'apprenant·e répond (choix, prénom, projet en texte libre).
- `activite-anna-rencontre.html` — version « BD » de la rencontre : bulles, poses illustrées, bouche animée sur canvas, sans vidéo (même moteur que Lisa).
- `activite-anna-conseils.html` — Anna doute (valeurs / vision / où elle en est) et demande conseil : quiz déguisé à 3 choix.

Les pages `activite-*.html` sont des portes d'entrée anti-cache à utiliser dans les iframes Genially.
